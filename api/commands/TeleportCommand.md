# TeleportCommand

**Extends:** {ref}`ESCBaseCommand <ESCBaseCommand>`
        
## Description

`teleport(object: String, target: String)`

Instantly moves an object to a new position.

#### Parameters

| Name | Type | Description | Required? |
|:-----|:-----|:------------|:----------|
|object|`String`|Global ID of the object to move|yes|
|target|`String`|Global ID of the object to use as the destination coordinates for `object`|yes|
